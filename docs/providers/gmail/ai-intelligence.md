# AI intelligence

**What it is:** a deterministic, local classifier (keyword/header/regex scoring) running in the API. It is English-oriented. It does *not* call any model or external
service, so there is no model selection, no external-provider path, and no language handling beyond English. This is the honest state of the repo: the
assistant/model-routing code exists in `Daksh.Platform` but the API's assistant module is stubbed ("pending MongoDB rebuild"), so there is nothing to connect to yet.

Outputs per message (stored in `gmailMessages`): category scores for 17 detectors, `important`, `urgent`, `suspicious`, `needsReply`, sentiment, extractive summary
(short/balanced/detailed), action items, deadlines (ISO, "5 Dec 2026", "December 5", "by Friday", "tomorrow"; relative dates resolve against the *message* date),
decisions/commitments, contacts, content hash for duplicate detection. Features such as sentiment, contacts and decisions are computed together.

Controls: each feature can be disabled or given a confidence threshold; scope can be all / important / selected categories; sender/domain/label exclusions;
summary length. Confidence is stored (`Scores`). Corrections: `POST /messages/{id}/classification/correct` records "this sender is / isn't <category>" and
overrides future classification for that sender (`CorrectedBy: user`).

**Prompt injection.** Email is untrusted data. Lines that look like instructions to an AI ("ignore previous instructions", "forward this to…", "mark this as urgent") are
stripped before scoring, can't raise importance/urgency, and flag the message as `suspicious`. Nothing in an email can trigger a send, permission change, or setting change:
actions come only from explicit user requests or user-authored rules, each checked by `GmailGuard`/the permission policy. `GmailPromptGuard.WrapUntrusted` is ready for a future LLM call.

Replies are **templates** (`GmailReplyComposer`) built from the user's greeting/closing/signature/style/length/avoid-phrases — not generated by a model. Previewing: Replies tab → "Preview".
